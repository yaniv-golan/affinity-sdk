# Field values (V1)

This service calls V1's field-value endpoints directly. To read or change a company's, person's
or list entry's field values, use `companies` / `persons` `get_field_values`,
`update_field_value` and `batch_update_fields`, or the list-entry methods, which use V2. See
[Field values](../../../guides/field-values.md).
