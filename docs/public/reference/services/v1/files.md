# Files

`list`, `all`, `iter`, `get`, uploads and downloads use V1: only V1 lists one person's,
company's or opportunity's files. `get_v2` (a file with a short-lived download URL) and
`list_v2`/`iter_v2` (every file visible to you, newest first) use V2 (Affinity API
2026-09-17+).
