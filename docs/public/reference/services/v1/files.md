# Files

`list`, `all`, `iter`, uploads and downloads use V1: only V1 lists one person's, company's or
opportunity's files. `get` (a file with a short-lived download URL) and `feed`/`iter_feed`
(every file visible to you, newest first) use V2 (Affinity API 2026-09-17+).
